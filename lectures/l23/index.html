    第 23 讲 · 量化¶

    权重量化档位，以及量化对速度和质量的影响

    视频制作中

    本讲视频将发布在 B 站，届时在这里嵌入播放。下面是讲稿正文。

    第二十三讲，我们讲量化。为什么同一个模型会有好几个版本的文件，它们的大小、速度和质量有什么区别。

    量化是什么¶

    用更少的比特存储权重

    • 原始权重通常是 16 位浮点数，每个参数占 2 字节
    • 量化：把权重压到 8 位、4 位甚至更低，按组共享缩放系数
    • GGUF 里的档位名：Q8_0 约 8 位，Q4_K_M 约 4 位（K 系列分组量化）
    • 好处：文件更小、内存更省，在 CPU 上通常也更快

    先说量化是什么。模型的原始权重通常是十六位浮点数，每个参数占两个字节。量化就是把权重压缩到八位、四位甚至更低，一组权重共享一个缩放系数。在 GGUF 文件里，你会看到 Q 八零、Q 四 K M 这样的档位名，数字大致就是每个权重的比特数。量化的好处是文件更小、内存更省，在 CPU 上通常还更快。

    要点

    量化 = 用精度换内存和带宽

    实测：Qwen3-8B 的 Q4 和 Q8¶

    a4_E5，llama-bench，Xeon Gold 6354，-t 16

    $ python assignment4/engine/bench.py --exp E5 --model models/Qwen3-8B-Q4_K_M.gguf --model models/Qwen3-8B-Q8_0.gguf
  "Qwen3-8B-Q4_K_M.gguf": {
   "pp512": 116.02,
   "tg128": 17.25,
   "size_gb": 5.02
  },
  "Qwen3-8B-Q8_0.gguf": {
   "pp512": 61.33,
   "tg128": 10.67,
   "size_gb": 8.7

    来看作业四第五个实验的真实数据。同一个 Qwen3 八 B 模型，Q 四版本文件约五 G 字节，Q 八版本约八点七 G 字节。预填充速度，Q 四每秒约一百一十六个 token，Q 八约六十一个。生成速度，Q 四每秒约十七个 token，Q 八只有十点七个左右。

    要点

    pp512 = 预填充速度，tg128 = 生成速度（tok/s）

    生成速度：Q4 明显更快¶

    a4_E5，Qwen3-8B，tg128 tok/s，Xeon Gold 6354，-t 16

    项目 数值
    Q4_K_M · 5.02GB 17.25
    Q8_0 · 8.7GB 10.67

    把生成速度画成柱状图就很直观。这组数据里，Q 八比 Q 四慢大约百分之三十八；试做阶段用 llama-bench 测的结论是慢百分之四十左右，两者一致。注意，计算量其实差不多，慢的原因在别处。

    要点

    本机 Q8 比 Q4 慢约 38%；M0 llama-bench 约 40%

    为什么权重越大越慢¶

    回顾第十七讲：解码阶段受访存限制

    • 解码每生成一个 token，都要把全部权重从内存读一遍
    • CPU 推理的瓶颈是内存带宽，不是算力
    • 权重字节数减半，每个 token 要搬的数据就近似减半
    • 所以 Q4 文件更小，生成也更快

    为什么权重越大越慢？回忆第十七讲，解码阶段每生成一个 token，都要把全部权重从内存里读一遍。在 CPU 上，瓶颈是内存带宽，而不是算力。权重的字节数越少，每个 token 需要搬运的数据就越少，速度自然就上去了。所以 Q 四既更小，又更快。

    要点

    访存瓶颈下：速度 ≈ 带宽 ÷ 权重大小

    代价：质量¶

    更低比特

    • 内存更省、速度更快
    • 能在 16GB 机器上跑 8B
    • 但量化误差更大

    更高比特

    • 更接近原始模型
    • 占用内存更多
    • CPU 上生成更慢

    当然，量化是有代价的。比特数越低，量化误差越大，模型质量可能下降。下降多少，取决于模型、档位和任务。课程的建议是：不要只看速度，要用你自己的 agent 任务去测解决率，再决定用哪个档位。

    要点

    没有免费的午餐：要用你自己的任务去测质量

    论文导读：GPTQ 与 AWQ¶

    只讲思路，不复述具体数字

    • GPTQ：逐层量化，用近似二阶信息补偿量化误差
    • AWQ：根据激活值找出少量重要权重通道，加以保护
    • 共同点：训练后量化，只需少量校准数据，不用重新训练
    • 阅读时关注：校准数据、比特数、评测指标怎么选

    本讲的阅读材料是 GPTQ 和 AWQ 两篇论文。GPTQ 逐层量化，利用近似的二阶信息，把量化带来的误差补偿到还没量化的权重上。AWQ 的观察是，少量权重通道对激活影响特别大，于是先保护这些重要通道再量化。两者都属于训练后量化，只需要少量校准数据。阅读时请关注它们怎么选校准数据和评测指标。

    要点

    训练后量化：少量校准数据，不重新训练

    小结¶

    • 量化用更少比特存权重：Q8_0、Q4_K_M 等档位
    • 实测 Qwen3-8B：Q4 5.02GB、17.25 tok/s；Q8 8.7GB、10.67 tok/s
    • CPU 解码受内存带宽限制，权重越小越快
    • 质量代价要用自己的任务来测

    小结一下。量化用更少的比特存储权重。实测中，Q 四比 Q 八更小也更快，原因是 CPU 解码受内存带宽限制。质量代价，需要用你自己的任务来衡量。练习是用实验五的数据，把速度乘以文件大小，看两个档位算出的带宽是不是差不多。下一讲，我们讲 MoE。

    课后练习

    用 E5 数据算 速度×文件大小：Q4 17.25×5.02≈87 GB/s，Q8 10.67×8.7≈93 GB/s。预期两者接近，说明解码受带宽限制
