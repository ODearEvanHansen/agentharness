    课程大纲¶

    共 14 周，28 讲。每讲由三部分组成：一段 3–5 分钟的导读视频（B 站，程序合成，见文末说明），讲稿全文，以及必读材料加一个 10–20 分钟、写明预期结果的小练习。每周预计投入约 2 小时用于阅读和练习，作业时间另计。答疑在 GitHub Discussions 和学习群进行。

    先修：熟练使用 Python；会用 git 和 Docker；了解 HTTP；能读简单的 HTML/JavaScript 和 TypeScript（作业 1 有前端部分，作业 2、3 需要读或写少量 TS）。不要求有 GPU 或机器学习背景。

    硬件：需要 x86_64 Linux，或 Windows + WSL2，不支持 macOS；磁盘 100GB（每个 SWE-bench 评测镜像约 3GB，建议按题拉取、用完删除）。 - 16GB 内存：可以完成作业 0–3，以及作业 4 的推理实验（8B 模型）。 - 32GB 内存：作业 4 的 L3 和作业 5 需要（30B-A3B 模型常驻内存约 28GB）。内存不足 32GB 的学员，作业 5 可以改用课程团队提供的本地模型基线数据，评分只看路由设计和云端实验。

    周 讲次 主题 要点 阅读 / 源码 作业
    1 L1 课程导论：agent 系统是什么 模型 + 循环 + 工具；本课路线；安全：隔离、key 泄露、提示注入 DSH README（中文版） 发布 A0（本周末截止）
    L2 DeepSeek API 入门 tool calling、思考模式与 reasoning_content、前缀缓存计价、一个约 20 行的最小 agent 循环 DeepSeek API 文档
    2 L3 DSH 导论 Cordis 插件架构、profile 与 patch、SDK 与运行时；如何关闭会话日志上传 DSH docs/user、python-sdk.md 发布 A1
    L4 事件与会话日志 turn/step/tool 事件、session.v4 日志、用量字段；子 agent 事件的最小示例 framework/events.md
    3 L5 子 agent 与编排 spawn/fork、深度上限（默认为 1）、结果回传；子 agent 什么时候值得用 subagent/README.md
    L6 Agent loop 剖析（上） 一个 step 的生命周期、请求组装、工具分发 agent-loop/README.md
    4 L7 Agent loop 剖析（下） 取消、失败恢复、配对补齐、并行工具调用 agent-loop/src/agent.ts A1 截止 · 发布 A2
    L8 评测基础设施 容器隔离、出网白名单（以及它防不住什么）、镜像分发、可复现性 infra/
    5 L9 工具设计 工具粒度对步数的影响、编辑工具、输出截断 DSH tools 子系统文档
    L10 评测 SWE-bench 的任务形态（issue → patch → 测试）、Verified 子集、数据污染、为什么需要难题集 SWE-bench 论文
    6 L11 上下文工程 系统提示、压缩、工具结果裁剪；token 都花在了哪里 compaction 子系统
    L12 前缀缓存与 request series 追加与改写的区别；在每一步写入当前时间的代价 agent-loop README
    7 L13 插件开发 tools/post-execute、agent/pre-step、agent/request-error；.ts 免编译加载 develop/basic A2 截止 · 发布 A3
    L14 成本与可靠性 重试、预算、flash 和 pro 怎么选
    8 L15 实验方法 对照、只改一个变量、重复与方差、统一计价口径 发布期末项目指南
    L16 课程团队方案复盘 一个在小实验里有效、在真实任务上无效的插件
    9 L17 推理基础 预填充与解码、KV cache、算力瓶颈与访存瓶颈 发布 A4（每个实验标注了学完哪一讲再做）
    L18 本地推理入门 Ollama 和 llama.cpp、GGUF；静默截断类问题的排查方法 llama.cpp README
    10 L19 批处理与调度 静态批处理与连续批处理、并发槽位 Orca 论文 A3 截止
    L20 前缀复用 cache_prompt、RadixAttention、agent 与推理服务的协同设计 SGLang 论文（只讲不做）
    11 L21 显存与内存管理 PagedAttention、KV 量化 vLLM 论文（只讲不做）
    L22 推测解码 草稿模型、接受率与加速比 Leviathan et al.
    12 L23 量化 权重量化档位与质量 GPTQ/AWQ 导读
    L24 MoE 激活参数与总参数 DeepSeek-V3 技术报告 A4 截止

    14 L27 前沿与开放问题 长任务、记忆、多 agent、评测污染
    L28 期末项目答疑与展示安排 复现要求、报告与展示形式 A5 与期末项目在第 16 周末截止

    评分（用于证书，不计学分）¶

    A0 是必做项，只判是否完成，作业 1 以它为前置。A1 占 10%，A2 占 15%，A3 占 20%，A4 占 20%，A5 占 15%，期末项目占 20%。每个作业都有自动检查和报告两部分。排行榜只做展示，不计入分数。

    预计花费（DeepSeek API）¶

    以下数字来自课程团队试做阶段（M0）的实测：原 20 题每题约 $0.02，难题集每题约 $0.04，作业 1 跑一次自动检查约 $0.003。作业 3 按每天调试 10 轮 20 题、持续两周估算，约 50–100 元。建议先在 8 道小题上调试，跑通后再上 20 题。全课总额要等外部试学员做完后才能校准，届时公布。

    关于视频¶

    导读视频由程序合成：画面和字幕由脚本生成，配音由 DeepSeek TTS 合成，视频里的演示数据都来自真实运行。完整内容以讲稿和阅读材料为准。
